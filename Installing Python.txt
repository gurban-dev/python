FIXING "pip is not recognized" ERROR (Windows)

This error usually means Python is installed, but its executable paths
were NOT added to your system PATH.

Follow these steps carefully:

--------------------------------------------------
STEP 1: Locate Python installation
--------------------------------------------------
1. Click the Windows Start button.
2. Type: python.exe
3. Right-click on "python.exe" and select:
   -> Open file location
4. In the folder that opens:
   - Click the address bar at the top
   - Copy the full path

   Example:
   C:\Users\YourName\AppData\Local\Programs\Python\Python311\

5. ALSO locate the "Scripts" folder inside this directory:
   Example:
   C:\Users\YourName\AppData\Local\Programs\Python\Python311\Scripts\

   You will need BOTH paths.

--------------------------------------------------
STEP 2: Open Environment Variables
--------------------------------------------------
1. Click the Windows Start button.
2. Search for:
   -> Environment Variables
3. Click:
   -> "Edit the system environment variables"
4. In the window that opens, click:
   -> Environment Variables...

--------------------------------------------------
STEP 3: Edit the PATH variable
--------------------------------------------------
1. Under "User variables" (top section), find:
   -> Path
2. Click:
   -> Edit...

3. In the new window, click:
   -> New

4. Paste the Python main folder path:
   (the one containing python.exe)

5. Click:
   -> New again

6. Paste the Scripts folder path:
   (the one containing pip.exe)

--------------------------------------------------
STEP 4: Save changes
--------------------------------------------------
1. Click OK
2. Click OK again
3. Click OK one more time to close all windows

--------------------------------------------------
STEP 5: Restart terminal
--------------------------------------------------
IMPORTANT:
- Close ALL Command Prompt / PowerShell windows
- Open a NEW terminal

--------------------------------------------------
STEP 6: Verify installation
--------------------------------------------------
Run the following commands:

python --version
pip --version

If both commands work, the issue is fixed.

--------------------------------------------------
COMMON MISTAKES TO AVOID
--------------------------------------------------
- Adding only python.exe instead of the full folder path
- Forgetting to add the Scripts folder
- Not restarting the terminal
- Editing System PATH instead of User PATH (either works, but be consistent)

If Python is not installed, download a stable release of
Python from the official Python website:
https://www.python.org/downloads/

Download the installer:
python-3.x.x-amd64.exe

Run the installer by double-clicking the downloaded file.

On Windows OS:
python-3.x.x-amd64.exe

E.g.
python-3.12.2-amd64.exe

At the bottom of the installer window check the following:
Add Python to PATH

Click "Install Now".

Verify installation:
python --version

pip --version

Linux OS:

sudo apt update
sudo apt install python3 python3-pip

or

Download the source code from the Python website:
Python-3.x.x.tgz

Extract the archive:
tar -xf Python-3.x.x.tgz

Move into the directory:
cd Python-3.x.x

Install build dependencies:
sudo apt update
sudo apt install build-essential libssl-dev zlib1g-dev \
libncurses5-dev libbz2-dev libreadline-dev libsqlite3-dev \
libffi-dev wget

Configure the build:
./configure --enable-optimizations

Compile Python:
make -j $(nproc)

Install Python:
sudo make altinstall

Verify installation:
python --version

pip --version
