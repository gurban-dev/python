A personal finance tracker that logs different transactions.

Organise the transactions, get summaries of income and expense.

View transaction data in a graph to see how much money is being
earned month over month.

Create a virtual environment:

Windows:
python -m venv <env_name>

E.g.
python -m venv venv

Mac or linux:
python3 -m venv <env_name>

E.g.
python3 -m venv venv

Activate the virtual environment:
source ./venv/bin/activate

Once you've activated your virtual environment,
the time is ripe for installing dependencies.

Windows:
pip install matplotlib

pip install pandas

Mac or linux:
pip3 install matplotlib

pip3 install pandas

Create a file that handles the main flow of the program:
main.py

Create a file for collecting data from the end user:
data_entry.py

A file named finance_data.csv will be generated by the
main.py program and will also act as the database for
the project.
