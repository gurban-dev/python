A function is standalone block of code that can reused.
In this context, the term "standalone" is used to describe
how functions can be called by themselves.

E.g. print('Hello World!')

In contrast, the .lower() method is not standalone because it
must be specifically called on a string object:
"Hello World!".lower()

Functions are different than methods.

A built-in function:
print("Hello")

A method is a function that belongs to an object.
(like a string, list, etc.).

A method of a string object.
"hello".upper()

A method of a list object.
[1, 2, 3].append(4)

Built-in functions are predefined by Python:
print(), type(), len()

User-defined functions are created by the programmer:
def greet():
	print("Good day!")

To invoke/call the user-defined greet() function:
greet()
